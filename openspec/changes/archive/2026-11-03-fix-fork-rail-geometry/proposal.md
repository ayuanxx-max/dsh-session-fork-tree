# 变更提案：分叉树几何规格化（固定横线长度）

## 为什么

「╰」横线长度此前按“父标题到子标题的间距”推导，导致：
- 第 1 层过长（父/子都顶格时仍跨 16px+）；
- 第 2 层减半后长度仍随缩进漂移；
- 每次改缩进都会把“横线减半 + 标题左移”这对逻辑改丢（0.9.19 回归）。

## 改什么

把横线长度从“推导值”改为**规格常量**，所有层级一致；标题起点由同一处代码保证紧贴横线末端。

## 影响

- `client.js` 的 `applyLayout`：`elbowW` 常量 10px；`shift = naturalElbow - 10`；`pad = naturalPad - shift`。
- 遥测新增断言字段，供闸门校验。
- 不改变排序、按钮位置、宿主逻辑。
